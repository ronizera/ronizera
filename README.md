**Tecnologias:** Java · Spring Boot · Spring Security · JWT · H2 · Swagger

API REST para controle de estoque com autenticação JWT, gerenciamento de produtos, categorias e movimentações de entrada e saída com histórico.

**Tecnologias:** Java · Spring Boot · Spring Security · JWT · H2 · Swagger
